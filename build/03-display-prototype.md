# Build 03 — Display prototype

1. Record exact panel model.
2. Record exact controller-board model/photo.
3. Verify controller input voltage/polarity.
4. Connect K8 HDMI to controller.
5. Connect eDP cable to panel with power removed.
6. Power controller.
7. Verify native 1920×1080, brightness control behaviour and stable signal.
8. Run for at least one hour before mounting.

Do not insert/remove the eDP cable while powered.
