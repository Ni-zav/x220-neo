# Build 06 — V0 transplant

## Required subsystems

- K8 board + stock cooler;
- 2×16 GB RAM;
- NVMe;
- HDMI-to-eDP display;
- USB keyboard/TrackPoint controller;
- stock 120 W adapter;
- temporary audio optional.

## Assembly order

1. Install board on nonconductive standoffs.
2. Route/secure fan and exhaust.
3. Install RAM/SSD.
4. Install display controller.
5. Route eDP cable through hinge path.
6. Install keyboard controller.
7. Connect display, USB keyboard controller and power.
8. Perform open-chassis boot.
9. Close shell and repeat thermal tests.

## V0 pass criteria

- can boot with shell closed;
- no cable rub at hinge;
- keyboard/TrackPoint stable;
- display stable;
- fan unobstructed;
- temperatures acceptable under sustained load;
- ports mechanically supported.
