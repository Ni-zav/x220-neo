# Build 04 — Measure the X220 and donor

Use `reference/Measurement-Sheet.md`.

Minimum measurement set before first full CAD:

- X220 lower-shell interior X/Y/Z envelope;
- hinge axis and swept keep-out;
- keyboard underside keep-out;
- palmrest screw locations;
- display cable path;
- naked K8 PCB outline;
- K8 mounting holes;
- every required port centreline and Z-height;
- cooler/fan envelope;
- SSD/RAM insertion/removal path;
- display controller envelope.

Measure twice. Record the tool and uncertainty.
