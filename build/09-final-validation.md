# Build 09 — Final validation

Use `reference/Test-Checklist.md` and create a `templates/Test-Run.md` record.

Minimum final test areas:

- boot / shutdown / sleep / wake;
- sustained CPU and combined CPU+iGPU load;
- RAM test;
- NVMe health and temperature;
- Wi-Fi/Bluetooth;
- every external port;
- keyboard/TrackPoint all keys/buttons;
- display brightness and hinge movement;
- fan intake/exhaust obstruction;
- chassis flex and hinge load;
- carry/shake test with power removed;
- screw-retention check after several thermal cycles.
