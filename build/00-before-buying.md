# Build 00 — Before buying

## Do first

- [ ] Photograph current X220 exterior/interior condition.
- [ ] Back up data.
- [ ] Decide which original X220 parts are sacrificial.
- [ ] Buy a spare lower shell before destructive cutting.
- [ ] Confirm budget ceiling.
- [ ] Prepare precision screwdrivers, caliper and multimeter.

## Stop/go gate

Do not order the final display, final print or custom PCB before the donor board is physically measured.
