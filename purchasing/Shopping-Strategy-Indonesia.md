# Shopping strategy — Indonesia

## Donor: hunt condition, not cosmetics

For this build the K8 Plus outer case has little value. Good candidates:

- used complete unit;
- barebone;
- scratched/dented enclosure;
- broken acrylic/top cover;
- seller unit with healthy motherboard but cosmetic damage.

Avoid:
- liquid damage;
- unstable power;
- missing original cooler;
- board repair history unless very well documented.

## RAM

Because Radeon 780M shares system memory, buy matched-capacity modules and run both SO-DIMM channels. A cheap **2×16 GB** configuration is better for this build than a single 32 GB module unless future capacity expansion is a stronger priority.

## Panel

Ask seller for **actual model code and connector position**. Marketplace titles often list many interchangeable models.

## Mechanical parts

Buy a cheap spare X220 bottom shell before cutting anything. Spare palmrests and bezels are also inexpensive enough to make experimentation less stressful.

## Import vs local

For imported donor hardware:

- compare seller checkout total, shipping and Indonesian import charges;
- keep invoice/order proof;
- use official Customs guidance for tax planning;
- do not assume a US-market displayed price is the landed Indonesian price.
