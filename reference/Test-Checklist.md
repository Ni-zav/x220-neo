# Test Checklist

## Electrical before first power
- [ ] Visual inspection.
- [ ] No metal debris.
- [ ] DC polarity confirmed.
- [ ] No shorts between main power rail and ground.
- [ ] Fan connected.
- [ ] Display-controller voltage confirmed.

## Boot
- [ ] Cold boot x5.
- [ ] Reboot x5.
- [ ] Shutdown x5.
- [ ] Sleep/wake x10.

## Input
- [ ] Every keyboard key.
- [ ] Fn combinations used daily.
- [ ] TrackPoint X/Y.
- [ ] Left/middle/right buttons.

## Display
- [ ] Native resolution.
- [ ] No flicker for 1 h.
- [ ] Hinge fully open/close x20 without cable disturbance.

## Stress
- [ ] CPU sustained load.
- [ ] iGPU sustained load.
- [ ] combined load.
- [ ] SSD sustained workload.
- [ ] RAM test.

## Mechanical
- [ ] No board flex.
- [ ] No screw boss cracking.
- [ ] Hinge load safe.
- [ ] Ports do not move inward when cables are inserted.
- [ ] No fan rub at any orientation.
