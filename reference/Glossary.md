# Glossary

- **APU** — CPU and integrated GPU in one package.
- **eDP** — Embedded DisplayPort, common laptop-panel interface.
- **LVDS** — older display interface used by the original X220 generation.
- **OCuLink** — external cable interface exposing PCIe lanes; K8 Plus exposes PCIe 4.0 ×4.
- **PD** — USB Power Delivery.
- **QMK** — open keyboard firmware framework.
- **BMS** — battery-management/protection system.
- **D-cover** — laptop bottom cover.
- **C-cover** — palmrest / keyboard-side upper chassis section.
- **Keep-out** — volume that other components must not intrude into.
