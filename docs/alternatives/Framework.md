# Alternative — Framework mainboard

Framework boards are architecturally cleaner for a laptop transplant because they are designed around battery/eDP/laptop power states, and Framework publishes unusually good mechanical documentation.

Why it is not the primary plan here:

- Indonesia availability/import path is worse;
- total platform cost can be higher;
- K8 Plus offers OCuLink and easier mini-PC sourcing/value.

Keep Framework as Plan B if power-management and battery integration become more important than donor cost.
