# Alternative — gaming-laptop motherboard donor

A gaming-laptop donor can provide an internal dGPU, but it radically raises integration difficulty:

- proprietary EC and battery interfaces;
- larger cooler and dual-fan geometry;
- higher peak power;
- display/eDP assumptions;
- proprietary daughterboards;
- much tighter Z-height constraints.

Treat this as a different project branch (`x220-neo-g`) rather than a V1 enhancement.
