# Alternative — GMKtec M6 Ultra

Lower-cost donor based on Ryzen 5 7640HS + Radeon 760M.

Pros:
- lower initial platform price;
- compact;
- DDR5 / NVMe / USB4.

Cons:
- weaker CPU/iGPU;
- **no native OCuLink**, so it loses one of the strongest reasons for choosing the K8 Plus.

Use only if K8 Plus pricing becomes unreasonable.
