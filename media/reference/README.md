# X220 visual reference set

These are curated engineering-reference images for the X220 Neo mechanical mock-up. The images are **remotely embedded from Wikimedia Commons**, not copied into this repository, which keeps Git history small while preserving traceable originals.

All six selected images are CC BY-SA 4.0 works by Siarhei V / Siarhei Besarab. Full per-file attribution and reuse notes are in [`reference/ATTRIBUTIONS.md`](../../reference/ATTRIBUTIONS.md).

> These photographs are excellent for understanding topology, relative placement, ribs, bosses and keep-outs. They are **not dimensional CAD**. Caliper measurements of the physical X220 remain the source of truth.

## 1. Whole-machine exploded reference

![Fully disassembled ThinkPad X220](https://commons.wikimedia.org/wiki/Special:Redirect/file/Disassembled%20Lenovo%20ThinkPad%20X220%20with%20components%20laid%20out.jpg?width=1280)

Original: https://commons.wikimedia.org/wiki/File:Disassembled_Lenovo_ThinkPad_X220_with_components_laid_out.jpg

Use for: assembly hierarchy, identifying retained parts, rough component relationships, and planning Blender collections.

## 2. Magnesium bottom case — interior

![Inside of X220 magnesium bottom case](https://commons.wikimedia.org/wiki/Special:Redirect/file/Inside%20of%20a%20Lenovo%20ThinkPad%20X220%20magnesium%20alloy%20bottom%20case.jpg?width=1280)

Original: https://commons.wikimedia.org/wiki/File:Inside_of_a_Lenovo_ThinkPad_X220_magnesium_alloy_bottom_case.jpg

Use for: D-cover tracing, ribs, screw bosses, drive bay, RAM-door area, vent locations, and initial chassis collision model.

## 3. Keyboard support bezel — underside

![Bottom of X220 keyboard bezel](https://commons.wikimedia.org/wiki/Special:Redirect/file/Bottom%20view%20of%20Lenovo%20ThinkPad%20X220%20keyboard%20bezel%20PN%20AP0S1000300.jpg?width=1280)

Original: https://commons.wikimedia.org/wiki/File:Bottom_view_of_Lenovo_ThinkPad_X220_keyboard_bezel_PN_AP0S1000300.jpg

Use for: keyboard underside keep-out, mounting points, cut-outs, and the upper boundary of the motherboard cavity.

## 4. Original motherboard installed without bezel

![X220 motherboard with keyboard bezel removed](https://commons.wikimedia.org/wiki/Special:Redirect/file/Disassembled%20Lenovo%20ThinkPad%20X220%20motherboard%20without%20keyboard%20bezel.jpg?width=1280)

Original: https://commons.wikimedia.org/wiki/File:Disassembled_Lenovo_ThinkPad_X220_motherboard_without_keyboard_bezel.jpg

Use for: understanding the original internal packing strategy, cable paths, port centerlines, cooler/exhaust relationship and structural clearances.

## 5. Original X220 cooling assembly

![X220 CPU cooling assembly](https://commons.wikimedia.org/wiki/Special:Redirect/file/ThinkPad%20X220%20CPU%20cooling%20system%20%28fan%20and%20heatsink%20assembly%29.jpg?width=1280)
