# Media

## Project-owned media

Store project-owned photos here using revision-oriented names, for example:

- `x220-shell-r0-top.jpg`
- `k8-board-r0-top-with-ruler.jpg`
- `k8-cooler-r0-side.jpg`
- `chassis-p0-interference-01.jpg`

Project-owned measurement photos should include a ruler/caliper where useful and should be referenced from `reference/Measurement-Sheet.md`.

## Third-party visual references

See [`reference/README.md`](reference/README.md) for a curated visual X220 teardown/mechanical reference set. Those images are remotely embedded from Wikimedia Commons rather than duplicated into Git history, and their CC BY-SA 4.0 attribution is recorded in [`reference/ATTRIBUTIONS.md`](../reference/ATTRIBUTIONS.md).

Avoid relying on marketplace photos as measurement truth. Reference images help reconstruct topology and keep-outs; physical measurements override them.
